# B.U.D.D.H.I. — website

Binary Understanding Data Driven Humanoid Intelligence: an offline-first assistant with 16.6 lakh passages,
nine interface languages and email accounts (Supabase) so your progress follows you between devices.

Live site: https://joshuagps.github.io/B.U.D.D.H.I/

- `index.html`, `engine.js`, `i18n.js`, `starter.js` — the app
- `config.js` — Supabase project URL and publishable key (public by design; row-level security protects accounts)
- `pack/` — the knowledge pack (gzip shards, opened on demand)
- `licenses.txt` — data licences
